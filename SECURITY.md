# Segurança

Não publique reuniões, transcrições, glossários, memória de vozes, credenciais ou
logs de autenticação em issues. Para vulnerabilidades com conteúdo sensível,
use o canal privado de segurança do GitHub, quando habilitado, ou abra uma issue
mínima pedindo contato privado, sem detalhes exploráveis ou dados pessoais.

O app não é uma fronteira de isolamento para agentes CLI instalados pelo usuário.
Revise plugins, regras e permissões desses CLIs. O Seed pede que eles usem apenas
o contexto enviado e respondam diretamente. Leia [Privacidade](docs/PRIVACY.md).

A primeira versão pública remove padrões pessoais do glossário e dos prompts,
usa exemplos fictícios e inclui testes de instalação vazia. Os dados existentes
na máquina do usuário são preservados; não são incorporados à distribuição.
